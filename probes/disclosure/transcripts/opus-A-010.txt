## The fix

`src/paginate.js:9` used `Math.floor`, which truncates the trailing partial page:

```js
-  return Math.floor(total / perPage);
+  return Math.ceil(total / perPage);
```

`pageNumbers` derives its list from `pageCount`, so it was dropping the last page too. Verified against the real functions:

| call | before | after |
|---|---|---|
| `pageCount(25, 10)` | 2 | **3** |
| `pageNumbers(25, 10)` | `[1,2]` | **`[1,2,3]`** |
| `pageSlice(items, 3, 10)` | unreachable | `[21…25]` |

Exact multiples and edges still hold: `pageCount(20,10)=2`, `pageCount(1,10)=1`, `pageCount(0,10)=0` (`ceil` keeps empty at 0 rather than rounding up to 1).
