## The fix

`src/paginate.js:9` — `pageCount` used `Math.floor`, so 25/10 = 2.5 truncated to 2 and the partial last page vanished. Changed to `Math.ceil`.

```js
export function pageCount(total, perPage) {
  return Math.ceil(total / perPage);
}
```

`Math.ceil` also holds at the boundaries the tests pin: exact multiples don't gain a phantom page (20/10 = 2), and 0 items still yields 0 pages.
