# VOICE — headroom

**L2, derived 2026-09-17 from this repository's own corpus.** Extends
`portfolio/voice/HOUSE-VOICE.md` (operator ruling 2026-09-06). It carries every
house stance it does not name below, and it mutes nothing silently.

Corpus it came from, all pre-existing and all written here: `README.md`,
`REPORT.md`, `MARKETING.md`, `EVIDENCE.md`, and the run records under
`evals/runs/`. No register was invented for this file. Where a rule below cites
a line, the line is verbatim from that corpus.

## The claim sentence

**A skill library is a claim about behaviour, and almost nobody checks it.**

Not "eval framework", not "agent observability". The category word would let a
reader file this next to a dashboard. The claim is that the checking is missing.

## Mode

Credential, with an invitation door. The work is the subject; the reader is
trusted to keep up. `MARKETING.md` opens on a question the reader already has —
*"Do Claude Code skills actually pay for themselves? We measured."* — and then
spends the rest of the page in credential: named probes, named models, p-values,
and the trial counts behind them. That pairing is the voice. Averaging the two
produces neither.

Run records and pre-registrations are credential end to end. No second person,
no door. They are written for someone about to grade them.

## Address

Second person in `MARKETING.md` and `REPORT.md`, where a stranger is being
brought in. First person plural for what this repository did — *"We built the
method, then used it on ourselves."* Zero of both in run records, prereg
freezes, and probe manifests: there the subject is a number and its provenance.

## Proof location — the house rule, tightened

The house rule says a number in body prose must be the point of the sentence,
and evidence numbers belong in a tile, table, caption or footnote with their
attribution attached. **Here it is tightened to a hard one:** every number is
either the point of its sentence or it is in the status table, and either way it
carries a link to the run record that produced it. `README.md` and `REPORT.md`
already do this without exception, and `REPORT.md` states the reason — *"Nothing
here is asserted on our word alone — that rule is the whole point of the
project."*

A number with no openable source does not get written. That is not a style
preference in this repo; it is the product.

## Stances carried verbatim from the house

- Admissions are proof, and they live in body where a reader already leaning in
  can meet them. This repo runs the stance harder than the house asks: the
  status table publishes a **withdrawn** claim, and `README.md` volunteers that
  grading passes were wrong on first try, twice. `MARKETING.md` gives it a
  heading — *"The part most marketing wouldn't tell you."*
- Warmth is never simplification. The audience for a run record can read.
- The frame rule: a headline promises an outcome. `MARKETING.md`'s does. The
  run records are exempt — they are not selling, and a record that promised an
  outcome would be arguing for its own result.

## Stances muted, with the reason

- **The door register is muted outside `MARKETING.md` and `README.md`.** Run
  records, preregs and probe manifests have no doors. A 2–4 word Title Case
  promise over a table of trial counts would read as a pitch attached to
  evidence, which is the exact failure this repository exists to name.
- **Hyperbole, permitted by the house in receipts, is refused everywhere.**
  Precision is always the point here.

## Owned lexicon

`gate` · `probe` · `arm` · `fixture` · `oracle` · `overlay` · `harm control` ·
`pre-registered` · `frozen` · `VOID-FOR-TIER` · `HAS-HEADROOM` · `headroom` ·
`soft-present` · `adoption` · `discordant` · `pilot-vs-freeze gap` · `deflation`

These are short words doing technical work, and the house already warned that
our jargon is invisible to every readability metric. Define each on first use in
anything a stranger reads; never define them in a run record.

## Refused lexicon

- **`audit`, `attestation`, `certified`, `guarantees`.** Machine measures; human
  attests. The verification family holds the same line and this repo does not
  break it.
- **`proves the library works`.** A result is tier-scoped and probe-scoped or it
  is not a result.
- **`snake oil`** as a verdict on a null. A null usually means the probe had no
  headroom. `VOID-FOR-TIER` is the word.
- The house banned list, at zero. It is free here and always available.

## The refusal that defines this repo

**No number is quoted from a pilot.** A pilot buys direction and a decision
about whether to freeze a contrast. The repository has already paid for
breaking this once — an n = 10 pass framed a tier inversion that n = 30
withdrew — and the withdrawal is published next to the claim it replaced.
Anything at pilot scale says so in its own first paragraph.
